# Agent trajectories

These are representative, sanitized execution trajectories for every agent used by Ocular:

- [Lesson Director: transfer learning](lesson-director-transfer-learning.md)
- [Clarification Agent: transfer learning](clarification-agent-transfer-learning.md)

The trajectories preserve instructions, inputs, tool calls, tool results, validation, retries, and human checkpoints. They intentionally exclude credentials, private data, and hidden chain-of-thought. Renderer, narration, and playback components are recorded as tools rather than agents.
